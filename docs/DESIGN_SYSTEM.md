# BIOS Hybrid Design System

Premium enterprise SaaS foundation with advanced AI-native interactions: intelligent, calm, trustworthy, analytical and accessible.

Initial tokens: Midnight #142438; Intelligence Blue #3478F6; Trust Green #16A085; Cloud #F2F5F9; Warning #E5A12B; Critical #DC5252. Validate contrast before finalising.

Use Inter or Geist; shadcn/ui as accessible foundation; Tailwind for tokens/layout; selected Aceternity components for distinctive moments; Animaster motion only when it communicates actual application state. Light theme default; dark theme optional.

Two related systems:
1. Application UI: navigation, assistant, governance, assets, approvals.
2. BI artifact design: report layouts, KPI cards, charts, filters, legends, labels and visual validation.

Share brand tokens, but keep artifact constraints explicit. Respect reduced-motion preferences. No fake progress.
