# Development Roadmap

0. Foundation: repo, instructions, Next.js/FastAPI shells, PostgreSQL/migrations, dataset ingestion, design tokens.
1. Intelligence: request intake, structured intent, asset/KPI discovery, evidence bundle, reuse-before-build.
2. Governance: eight deterministic rules, duplicate candidates, owner/lineage checks, explainable lifecycle recommendation, approval/audit.
3. Artifact Factory: DashboardSpec, templates, validation, two-request repeatability demo, Power BI feasibility spike.
4. Enterprise lifecycle: asset registry, ownership, roles, versions, publication state, verification watch.
5. Differentiators: sprawl warnings, n8n monitoring/notifications, optional UNO Q, end-to-end demo.

Keep one end-to-end path runnable at every milestone. Prefer an integrated working product over disconnected feature demos.
