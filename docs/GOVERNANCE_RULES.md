# Governance Rules

Implement the eight builder-pack rules as deterministic, testable code. Confirm exact wording and thresholds against the workbook; do not invent thresholds.

1. Reuse before build.
2. Canonical KPI first.
3. Owner required.
4. Lineage required.
5. High reach requires trust.
6. Do not migrate waste.
7. AI-ready semantics.
8. Explain every lifecycle action.

Each finding includes rule ID, asset, evidence references, severity, explanation and next step. Missing data is unknown, not compliant. Hard constraints cannot be overridden by model scores. Retirement requires dependency, owner, criticality and replacement checks. Consequential actions require approval and audit history.
